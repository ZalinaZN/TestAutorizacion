# Автоматизация тестирования формы авторизации (Page Object Model)

Данный проект представляет собой **набор автотестов для проверки формы авторизации** веб-ресурса. Архитектура проекта построена на основе паттерна проектирования **Page Object Model (POM)**, что обеспечивает разделение логики тестов и структуры веб-страниц, упрощая поддержку и масштабирование кода.

## 🛠 Технологический стек

* **Язык программирования:**   Java  
* **Инструмент автоматизации:**  Selenium WebDriver 
* **Шаблон проектирования:** Page Object Model (POM)

## 📁 Структура проекта

```text
├── pages/                  # Классы страниц (Page Objects)
│   ├── base_page.py        # Базовый класс с общими методами для всех страниц
│   └── login_page.py       # Класс страницы авторизации (локаторы и действия)
├── tests/                  # Тест-кейсы
│   └── test_login.py       # Тесты формы авторизации
├── config/                 # Конфигурационные файлы (URL, учетные данные)
├── requirements.txt        # Зависимости проекта (или package.json / pom.xml)
└── README.md               # Документация проекта
```

## 🧪 Покрытые тест-кейсы

В проекте реализованы проверки для следующих сценариев:

* **Позитивные сценарии:**
  * Успешная авторизация с валидными данными.
* **Негативные сценарии:**
  * Авторизация с неверным паролем.
  * Авторизация с несуществующим логином/email.
  * Попытка отправки пустой формы.
  * Проверка валидации формата поля Email (если применимо).
